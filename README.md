# 浅草健身计划

网页：<https://kyoushingi-lab.github.io/asakusa-fitness-plan/>

手机训练计划与个人记录本：灵活 A→B→C 循环、9 种器械图文和视频、训练日历、重量历史、打卡、器械设置、爬坡计时与饮食建议。每周两次也可接着循环，不固定星期。

## 账号与游客

目前首页优先显示“直接开始训练”，账号与同步设置默认折叠。按使用者要求，邮箱配置暂缓，cloud-config.js 的 emailLoginPaused=true 隐藏新邮箱登录表单；已有登录会话的账号隔离和同步代码保留。恢复配置后再将此标记设为false，并验证真实邮件。

游客无需注册，四类记录仅保存在当前浏览器。正式账号采用 Supabase 邮箱登录链接；每个账号独立保存重量、日历、打卡和器械设置，可在不同设备登录同一个邮箱同步。计时器在当前设备运行。

退出或换账号会重新载入对应记录；新账号没有其他人的重量与设置。游客记录不会自动上传，首次同步成功后可展开导入预览，明确点击才合并；保留账号已有同日训练与已有设置。原始游客数据保留。

旧版数据按原同步账号归属迁移；无归属的旧数据成为本机游客记录，原始存储键保留为恢复备份。不要在公共仓库提交实际训练历史、私人导出文件或登录凭据。

**发信服务仍需配置**：Supabase 默认邮件仅供项目团队邮箱测试。让其他人注册与登录前，项目所有者需配置自定义 SMTP 或正式启用的登录提供商。不能通过把使用者加入后台项目团队来代替注册。

## 使用与备份

用 Safari 或 Chrome 打开。填写重量后停顿一秒或离开输入框，记录填写时的本地日期、时间和公斤数；相同器械同一天连续相同重量不重复记。重量记录不等于完成训练。器械档位单独修改，空白显示“待记录”。

日历选择实际训练日期，再记录 A、B 或 C；支持补记、更正、删除与当前页撤销，未来日期不能预记完成。下一次推荐以最新训练日期为准。

“导出备份”和 CSV 导出重量历史；“导入个人训练档案”可导入日期、完成／跳过动作与重量。其余日期保留，无实际时间的档案记录显示“时间未记录”。JSON/CSV 的重量备份不包含全部账号日历或器械设置，清理设备数据前应先确认账号同步成功。

原生 details 内置全部动作说明；禁用脚本也可展开阅读。照片相册默认收起，保留主图、操作、视频和调节实拍。已核对臀部机 HS-HG、腹肌机 SS-AB 与髋外展机 HS-HAB；来源见 MEDIA-SOURCES.md。

计时器显示大号坡度与速度，五段训练之间各留十秒调整参数：三十分钟训练加四次间歇，共三十分四十秒。网页不控制跑步机。

## 开发与部署

GitHub Pages 使用 main 分支根目录，静态文件直接部署：

- index.html / styles.css：完整训练内容与手机布局。
- app.js：训练日历、重量、导入导出、打卡与计时。
- accounts.js：登录、游客、退出与显式导入界面。
- account-store.js：不可变账号分区、旧数据迁移与逐项版本合并。
- account-sync.js：同账号四类记录同步，离线重试、分页与批处理。
- vendor/supabase.js：Supabase JavaScript 2.118.0。
- cloud-config.js：可公开的项目 URL 与 publishable key；禁止放服务端密钥。
- supabase/schema.sql：新项目的重量表初始化。
- supabase/account-state.sql：新增私人账号状态表及合并函数；现有项目已应用。

重量历史只允许本人读取和追加。账号状态按日历日期／单个设置存储版本，删除保留标记，避免离线设备恢复已删除日期；冲突按版本和设备标识确定结果。表启用账号隔离，合并函数使用 SECURITY INVOKER，所有者由服务器的 auth.uid() 决定。

## 验证

安装测试依赖与 Playwright WebKit、Chromium 后运行 npm run test:webkit / npm run test:chromium；核心与同步逻辑运行 npm run test:accounts。所有测试使用虚构日期、合成账号及隔离浏览器，不发送真实登录邮件。

supabase/verify-account-state.sql 检查本人读写、跨账号隔离、匿名拒绝、并发冲突、删除标记及批次限制；测试用户与数据在事务中回滚。

npm run build:offline 在仓库外生成完整单文件 HTML，图片、样式、脚本全部内嵌。离线文件使用本地游客记录，与在线网址分开保存。WebKit 手机模拟不等于 iPhone 真机测试；真实邮件投递仍需发信服务配置后验证。
